CHRISTINE'S BIRTHDAY WEBSITE
============================

This version includes the song you supplied as the background music.

Project files:
- index.html
- style.css
- script.js
- assets/christine-song.mp3 (your uploaded song)

PREVIEW:
Open index.html in a browser and tap the music button to start the song.
Tap it again to pause. The song repeats while playing.

PUBLISH:
Upload the entire project, including the assets folder and MP3 file, to your web host.
Do not upload only the HTML/CSS/JS files or the music will not be found.

NOTE:
Browsers block automatic audio playback until the visitor taps the music button.
